## 🚀 如何运行测试

### 方法1：使用批处理脚本 (Windows)
```bash
cd backend
test_system.bat
```

### 方法2：使用Python脚本
```bash
cd backend

# 运行所有测试
python run_all_tests.py --all

# 运行基础测试
python run_all_tests.py --basic

# 运行API测试
python run_all_tests.py --api

# 运行单元测试
python run_all_tests.py --unit
```

### 方法3：直接运行测试文件
```bash
cd backend

# 运行基础测试
python tests/test_system_basic.py

# 运行API集成测试
python tests/test_api_integration.py

# 使用pytest运行
python -m pytest tests/test_system_basic.py -v
```

### 方法4：运行现有单元测试
```bash
cd backend

# 运行所有pytest测试
python -m pytest tests/ -v

# 运行特定测试
python -m pytest tests/test_signal_ato_controller.py -v
```
