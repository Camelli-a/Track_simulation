# 视景系统数据需求说明

## 我需要你们提供以下数据：

### 1. 车辆位置数据
```
{
    "vehicle_id": "TRAIN-001",          # 车辆ID
    "position_m": 1234.5,               # 绝对位置（米）
    "speed_mps": 16.67,                 # 速度（米/秒）
    "direction": 1,                     # 方向：1=正向，-1=反向
    "line_id": "LINE-1"                 # 线路ID
}
```

### 2. 信号机状态数据
```
{
    "signal_id": "SIG-01",              # 信号机ID
    "state": "green",                   # 状态：red/yellow/green
    "signal_type": "区间"               # 信号机类型
}
```

或者批量提供：
```
[
    {"signal_id": "SIG-01", "state": "green"},
    {"signal_id": "SIG-02", "state": "red"},
    # ... 总共77个信号机
]
```

### 3. 道岔状态数据
```
{
    "switch_id": "SW-01",               # 道岔ID
    "position": "normal",               # 位置：normal/reverse
    "state": "normal"                   # 状态
}
```

或者批量提供：
```
[
    {"switch_id": "SW-01", "position": "normal"},
    {"switch_id": "SW-02", "position": "reverse"},
    # ... 总共29个道岔
]
```

### 4. 其他车辆数据（可选）
```
[
    {
        "vehicle_id": "TRAIN-002",
        "position_m": 2000.0,
        "speed_mps": 15.0,
        "direction": 1
    },
    # ... 最多128辆
]
```

---

## 数据格式要求

### 单位换算（我来处理）
- **位置**：你给我米(m)，我转毫米(mm)
- **速度**：你给我米/秒(m/s)，我转毫米/秒(mm/s)
- **边号**：你给我位置和线路，我查表转边号(1-40)

### 更新频率
- **每100ms**发送一次数据
- 数据需要实时更新
- 如果数据不变也要发送当前状态

### 数据有效性
- 位置需要在轨道范围内
- 速度 ≤ 33.333 米/秒（≈120公里/小时）
- 方向只能是 1 或 -1



## 调试与测试

### 测试数据示例
```json
{
    "vehicle_id": "TRAIN-001",
    "position_m": 100.0,
    "speed_mps": 5.0,
    "direction": 1,
    "line_id": "LINE-1"
}
```

### 验证方法
1. 给我测试数据
2. 我发送到视景系统
3. 观察视景系统显示
4. 调整参数直到正确显示

---

## 注意事项

1. **边号范围**：1-40，超出会"着火"
2. **起点道岔**：所有位移都相对于起点道岔
3. **实时性**：100ms周期，延迟不能太大
4. **数据一致性**：位置和边号必须匹配
