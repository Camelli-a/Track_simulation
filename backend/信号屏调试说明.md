# 司机台信号屏调试指南

## 简介

本系统用于连接和调试司机台的信号显示屏（MMI）。根据《司机驾驶模拟台信号屏协议》，信号屏作为TCP客户端连接到上位机（我们的服务器）。

## 通信参数

- **协议**: TCP
- **服务器IP**: 192.168.100.121（实际设备地址），测试时可以使用 127.0.0.1
- **端口**: 9999
- **帧长度**: 66字节定长报文
- **帧头**: 0x55 AA 55 AA (小端DWORD: 0x55AA55AA)

## 调试工具

我为你创建了两个调试工具：

### 1. 主调试工具 (`debug_signal_display_fixed.py`)
这是完全独立的版本，不依赖现有代码，适合快速测试。

#### 使用方法：

```bash
# 启动服务器（监听所有网卡）
python debug_signal_display_fixed.py server --host 0.0.0.0 --port 9999

# 启动模拟客户端（连接本地服务器）
python debug_signal_display_fixed.py client --host 127.0.0.1 --port 9999 --interval 0.1

# 解析十六进制数据
python debug_signal_display_fixed.py hexview "55AA55AA0042003200018E93F46C800000000000000003070C0A000000030D01010100002041C000003DCD4000A041000001010000000100000003E90000449C8000"
```

#### 参数说明：
- `--host`: 服务器IP地址（默认: 0.0.0.0）
- `--port`: 端口号（默认: 9999）
- `--interval`: 发送间隔（秒，默认: 0.1）
- `--count`: 发送次数（0=无限，默认: 0）

### 2. 高级调试工具 (`debug_signal_display.py`)
这是更完整的版本，集成了现有的`SignalDisplayServer`类（如果可用）。

## 联调步骤

### 准备阶段：
1. 确保信号屏设备IP配置为 192.168.100.121
2. 确保服务器IP在同一个网段（或使用端口转发）

### 调试阶段：
1. **启动服务器**：
   ```bash
   python debug_signal_display_fixed.py server --host 192.168.100.121 --port 9999
   ```

2. **查看连接状态**：
   - 服务器会显示连接状态和接收帧数
   - 查看logs目录下的日志文件

3. **模拟客户端测试**（可选）：
   ```bash
   python debug_signal_display_fixed.py client --host 192.168.100.121 --port 9999
   ```

4. **解析抓包数据**：
   ```bash
   python debug_signal_display_fixed.py hexview "你的十六进制数据"
   ```

### 问题排查：

1. **连接失败**：
   - 检查IP地址是否正确
   - 检查防火墙设置
   - 使用`ping`测试网络连通性

2. **数据解析错误**：
   - 检查帧长度是否为66字节
   - 检查帧头是否为0x55AA55AA
   - 使用十六进制解析工具验证数据格式

3. **日志文件**：
   - 所有接收的原始数据保存在`logs/signal_server_*_hex.txt`
   - 解析结果保存在`logs/signal_server_*.log`

## 注意事项

1. **IP地址配置**：
   - 实验室设备：使用 192.168.100.121
   - 本地测试：使用 127.0.0.1 或 0.0.0.0

2. **日志文件**：
   - 所有会话都有时间戳记录
   - 支持网络抓包格式解析

3. **性能**：
   - 服务器支持多客户端连接
   - 默认10Hz发送频率（可调整）

4. **兼容性**：
   - 支持Windows/Linux系统
   - 纯Python实现，无需特殊依赖
